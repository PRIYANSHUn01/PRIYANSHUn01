## 🎓 Dissertation Projects

### 🔐 [Secure Cloud Data Storage](https://github.com/PRIYANSHUn01/secure-cloud-data-storage) — MSc 1st Semester
> Three-Way Protection Framework: KTGCN Intrusion Detection + Hybrid AES-ECC-RSA + Homomorphic Encryption

<table>
<tr>
<td width="50%">

**Layer 1 — Authentication**
- PBKDF2-SHA256 (100k iterations)
- ECC P-256 ECDSA challenge-response
- RSA-2048 digital certificates
- HMAC-SHA256 session tokens

**Layer 2 — Intrusion Detection (KTGCN)**
- Koopman Layer (truncated SVD)
- 3× Graph Convolutional layers
- Global Attention Pooling

</td>
<td width="50%">

**Layer 3 — Adaptive Encryption**
- Level 1: Public (no encryption)
- Level 2: AES-256-GCM
- Level 3: AES-256-GCM + ECC P-256
- Level 4: + Martino Homomorphic Encryption

**Results**
| Metric | Value |
|--------|-------|
| Accuracy | **99.83%** |
| Precision | **99.46%** |
| FPR | **0.24%** |

</td>
</tr>
</table>
