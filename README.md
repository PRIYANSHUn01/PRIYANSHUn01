### 🚀 Dissertation Project

#### 🚦 [Smart Traffic Monitoring System](https://github.com/PRIYANSHUn01/smart-traffic-monitoring)
> Real-time AI-powered traffic violation detection using YOLOv8, ByteTrack and Deep Learning

- **Vehicle Detection** — Custom YOLOv8 model + ByteTrack (24 FPS on CPU)
- **Helmet Violation Detection** — 88.1% precision, 5-frame confirmation window
- **Triple-Riding Detection** — IoU-based person overlap (88.9% precision)
- **Number Plate OCR** — EasyOCR + 10-frame voting buffer (84.3% accuracy)
- **REST API** — FastAPI, 52 req/s under 50-thread load, 0 errors
- **Live Dashboard** — Streamlit + Plotly, auto-refresh every 2 seconds
- **Docker** — Full containerisation, `docker-compose up` one command
